A 1D (One-Dimensional) Array stores multiple elements of the same data type in a single row.

1. Syntax
    int a[5];

*   Here:
-> int → Data type
-> a → Array name
-> 5 → Number of elements

How to access elements
-> a[0] → 10
-> a[1] → 20
-> a[2] → 30
-> a[3] → 40
-> a[4] → 50

* Remember: Array indexing starts from 0, not 1
